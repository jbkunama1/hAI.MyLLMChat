Einstellungen

Die Backends (Chat, Image, MCP) werden ausschließlich über Environment-Variablen konfiguriert (HAI_DEFAULT_..., HAI_MCP_...).

Diese UI liest die aktuelle Konfiguration über /api/config aus dem Backend aus.

Weitere Funktionen (z.B. Model-Auswahl, MCP-Tools) kannst du später direkt im Code erweitern.
